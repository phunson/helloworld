# ASCII Art Printer
A small Python project that prints ASCII art to the terminal. Good for learning multiline strings, basic I/O, and simple console demos.

# Project structure
main.py — example script that prints ASCII art
README.md — this file
examples/ — (optional) folder to keep additional ASCII art files



# Installation & Running
Install Python 3.x (verify with python3 --version or python --version).
Save the code above as main.py.
Run:
# macOS / Linux:
(optional) chmod +x main.py
./main.py or python3 main.py
# Windows:
python main.py

# Example output
Running the script prints "Hello World" followed by two ASCII art images defined in the script.
